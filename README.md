
# Portafolio de Redes y Telecomunicaciones

**Ingeniería en Conectividad y Redes | Laboratorios y documentación técnica**

## Sobre este repositorio

Este repositorio reúne mis proyectos prácticos de redes y telecomunicaciones, con el objetivo de demostrar conocimientos técnicos mediante laboratorios documentados, configuraciones, diagramas de topología y pruebas de conectividad.

## Áreas de estudio

- Direccionamiento IPv4/IPv6 y subnetting
- Switching y segmentación mediante VLAN
- Routing estático y dinámico
- Servicios de red: DHCP y NAT/PAT
- Listas de control de acceso (ACL)
- Diagnóstico y resolución de problemas de conectividad

## Laboratorios

Los siguientes proyectos se incorporarán a medida que sean desarrollados y validados.

| Proyecto | Estado |
|---|---|
| VLSM y conectividad IPv4 básica | Completado |
| VLAN, trunking y router-on-a-stick | Proximo |
| DHCP para múltiples subredes | Pendiente |
| Port security y seguridad de switching | Pendiente |
| ACL y control de comunicación | Pendiente |
| OSPF y redes interconectadas | Pendiente |
| Troubleshooting y fallas provocadas | Pendiente |

## Herramientas

Cisco Packet Tracer y herramientas de diagnóstico y simulación, según los requerimientos de cada laboratorio.

## Metodología de trabajo

Cada laboratorio incluirá, según corresponda:

- Objetivo y escenario del ejercicio.
- Diagrama de topología y plan de direccionamiento.
- Configuraciones y explicación técnica.
- Pruebas de conectividad y resultados.
- Diagnóstico de fallas, soluciones y conclusiones.
